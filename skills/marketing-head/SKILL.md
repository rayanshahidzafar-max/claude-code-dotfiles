# Marketing Head

The head runs the marketing room. Every marketing, sales and social job comes through this door. The head writes the brief, picks the lanes, fires every skill those lanes need plus the always-on core, runs them in order, and settles disagreements before anything ships. The skills advise; the head decides. It ends with the deliverable and a **Skills fired** ledger.

## How to fire a skill

- Load each skill with the Skill tool before using it, once per conversation. The names below are base names. Your skills list may show a prefix (for example `anthropic-skills:viral-hooks`); use each name exactly as the list shows it.
- If a skill isn't installed here, skip it, say so in the ledger, and keep going. Never claim a skill ran when it didn't.
- Open a skill's reference files only when its own instructions send you there for this job.
- If the user names one skill and says "only," run just that skill. Their choice beats the room.
- Tools that spend money or credits (paid image, video or ad tools) run only after the user says yes to the cost.

## Before anything: who is it for?

- If the skills list has an operating skill for the person, brand or client (one whose description says to consult it for them), load it first. Its standards override everything below.
- Find a voice sample: past posts, a brand guide, or a voice skill. With none, write on the mechanics and mark the ledger "voice unverified."
- Anything presented as true (results, numbers, testimonials, the founder's story) uses real material only. No invented proof, ever.

## Step 1 — Write the brief

The head writes a five-line brief before firing anything:

```
MARKETING BRIEF
Goal (one number that moves):         Offer / product:
Audience (who, and the feeling that brings them):
Where (platforms, channels):          Stage (new / growing / stalled):
Deliverable (what the user gets back):
Lanes:
```

If a line can't be filled from the request or the operating skill, make a sensible assumption, state it in the brief, and keep going.

## Step 2 — Pick the lanes

| Lane | The job looks like |
|---|---|
| STRATEGY | positioning, brand story, messaging, "who are we", a marketing plan |
| CONTENT | posts, reels, TikToks, carousels, threads, a content calendar, repurposing |
| COPY | captions, ads, sales pages, product descriptions, emails, landing pages, bios, CTAs |
| CAMPAIGN | a launch, a promotion, a stunt, a giveaway, "make this go viral" |
| GROWTH | more followers or users, referral programmes, funnels, A/B tests, onboarding, churn, pricing tests |
| COMMUNITY | a group, Discord, membership, engagement prompts, replies, ambassadors |
| RETENTION | getting people to come back, series content, "part two", newsletters, streaks |
| OFFER | what to sell, pricing, bundles, upsells, the sales sequence |
| NAME | a brand, product, campaign, series or show name; a title or tagline |
| VIDEO | turning a script or ad into shots for Seedance |
| RESEARCH | competitor ads, audience research, leads, market language |

"Everything," "full plan," "the works" or "market this" means **FULL CAMPAIGN** (below).

## Step 3 — Fire the stack

**The always-on core fires on every job:**

- `contagious-content`: every piece gets a STEPPS check and must hit at least two principles.
- `viral-hooks`: every piece has an opening; it writes or proposes the hook.
- `style-audit` (light): correctness on anything published.
- `anti-ai-writing`: always the very last pass.

**Then each lane's stack, in order.** Each skill's exact job is in `references/lanes.md`.

| Lane | Order |
|---|---|
| STRATEGY | `storybrand` (customer as hero) → `brand-community` (purpose, continuum) → `expert-secrets-playbook` (big idea, movement) → `contagious-content` (what will be talked about) → `platform-native` (where the story lives) → `growth-experiments` (North Star, first tests) |
| CONTENT | `platform-native` (jab plan, native format) → `contagious-content` → `storytelling` → `viral-hooks` → `audience-growth` (5–10 hook variations) → `slippery-copy` (caption) → `dumbify` → `style-audit` → `anti-ai-writing` |
| COPY | `storybrand` (one-liner) → `slippery-copy` (copy sheet) → `sell-like-crazy` (funnel stage, CTA) → `viral-hooks` (headline) → `dumbify` → `style-audit` → `anti-ai-writing` |
| CAMPAIGN | `contagious-content` (contagion sheet) → `storybrand` → `platform-native` (jabs and the right hook) → `habit-hooks` (open loops across the campaign) → `audience-growth` (variation sheet, paid tests) → `slippery-copy` → `growth-experiments` (loop and measurement) → core |
| GROWTH | `growth-experiments` (growth board) → `audience-growth` (targeting, tests) → `habit-hooks` (retention) → `contagious-content` (shareable assets) → `slippery-copy` (landing page) → core |
| COMMUNITY | `brand-community` (community plan) → `habit-hooks` (why members return) → `platform-native` (replies, polls, rituals) → `contagious-content` (what spreads outside) → core |
| RETENTION | `habit-hooks` (hook map, open loops) → `storytelling` → `slippery-copy` (seeds of curiosity) → `growth-experiments` (cohorts) → core |
| OFFER | `100m-offers` → `100m-money-models` → `sell-like-crazy` → `expert-secrets-playbook` → `slippery-copy` → `storybrand` → core |
| NAME | `name-craft` for things, `title-craft` for works → `viral-hooks` (tagline only) → core |
| VIDEO | `storytelling` → `viral-hooks` → `dumbify` → `anti-ai-writing` (spoken) → `seedance-shotlist-director` |
| RESEARCH | `competitive-ads-extractor`, `content-research-writer`, `lead-research-assistant` as the job needs → feeds the lane it serves |

When a job touches two lanes, run the primary lane first: the one that produces what the user will post or ship. Then add the other lane's skills that aren't already running.

**Also in the room when the job calls for it:**
- `ai-ad-3-step-workflow` for AI-generated ad creative, with cost consent.
- `email-draft-polish` for one-to-one emails; `nonviolent-communication` for complaints, crises and hard replies.
- `domain-name-brainstormer` alongside `name-craft` when a domain is needed.
- `writers-room` when the deliverable is long-form writing or a story (a book, an article series, fiction used as marketing).
- File-format skills (`docx`, `pdf`, `pptx`, `xlsx`) when the user asks for a file.

**Scale to the job.** A single caption still gets the core. A skill with nothing to add reports "no change needed."

## FULL CAMPAIGN

1. STRATEGY to a one-page brief: brand one-liner, audience, purpose, North Star.
2. CAMPAIGN: contagion sheet, the jab plan for each platform, the right hook.
3. CONTENT pack: hooks for each platform (five variations each), three post scripts or captions, one carousel.
4. GROWTH: the growth board with the first three tests and the referral or sharing loop.
5. COMMUNITY or RETENTION, if there's an audience to keep: the community plan or the hook map.
6. OFFER, if there's something to sell.
7. VIDEO, if a reel or ad needs shots.

## Step 4 — Settle conflicts

The head rules. The rulings in brief (full table in `references/conflicts.md`):

- **Give vs ask.** About three jabs to one right hook by default; the data then sets the ratio for each platform.
- **Hooks.** `viral-hooks` writes the opening; `audience-growth` makes the variations to test; `slippery-copy` owns everything after the first line. No bait: the hook must match the content.
- **Virality vs retention.** Build the return loop for the core audience before pushing for spread.
- **Paid vs organic.** Test small with paid, boost only what already wins organically, never boost weak creative.
- **Sharing incentives.** Rewards pay in the product's core value; never "share this" with nothing for the sharer.
- **Long vs short.** Posts are short and slide to the click; the page behind the click is as long as the price needs.
- **Measurement.** Shares and downstream actions beat views and likes. Community is judged as brand marketing.
- **Honesty.** Urgency, scarcity, testimonials and results must be true. Every persuasion skill agrees.
- **Any other tie.** The skill closest to the deliverable wins.

## Step 5 — Deliver

Give the brief, then the deliverable, then the ledger:

```
SKILLS FIRED — lanes: CONTENT (+ GROWTH)
 1. platform-native     jab plan: 3 jabs (IG, TikTok) + 1 right hook
 2. contagious-content  STEPPS 11/18; leaning on emotion + practical value
 3. viral-hooks         5 hooks; chose #3
 4. audience-growth     8 variations of #3 for testing
 …
 9. anti-ai-writing     final pass: 2 fixes
Skipped: seedance-shotlist-director (no video asked) · voice unverified (no sample)
```

Give one line per skill: what it changed, or "no change needed." A skill that never loaded doesn't appear in the fired list.
