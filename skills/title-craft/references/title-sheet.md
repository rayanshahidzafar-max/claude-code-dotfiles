# The Title Sheet

Fill it in for any titling job. For a book, keep it with the project; for a story in the story folder, paste it into `08-final.md`'s notes at the polish station.

```
TITLE SHEET — <project>

JOB:            <book / subtitle / chapters / series / article / post / video / email / listing>
FICTION OR NONFICTION:
THE READER:     <one specific person; what they call themselves>
  problems:     <their words>
  questions:    <their words>
  roadblocks:   <their words>
  results:      <their words>
AWARENESS:      <knows only the problem / seeking a solution / knows us>
REASONS WHY:    <the two strongest for this reader>
WHAT SELLS NOW: <3–5 bestselling titles in the category and the pattern they share>

PROMISE (nonfiction):
  hurdle:       <their verb>
  prize:        <their result words>
  timing:       <believable>
  eliminator:   <even if ... / without ...>
HOOK:           <one-sentence true story or angle>
SOLID THING (fiction): <character / place / object / theme / genre the title names>

CANDIDATES (20+):
  1.
  2.
  ...
SHORTLIST (3–5), each with one line of why:
CHOSEN TITLE:
SUBTITLE / TAGLINE:
SKIM PATH:      title + subtitle + chapter titles read alone tell the pitch?   Y / N
SCRATCH CHECK:  spelling · copycat · restrictive · annoying · tame · insider · pronounce
CHAPTER TITLES: <list, with the pattern named>
SERIES:         <series name; book-title pattern; how it extends to book 5>
TESTS TO RUN:   <ads / emails / listing subtitle: one variable each>
```
