# Commonly Misused Words and Expressions

A working subset of the book's list, paraphrased. The whole list rests on one principle: use each word in its exact sense, and cut the words that only pad. [S&W IV]

| Word or phrase | The problem | Prefer |
|---|---|---|
| aggravate | means "make worse," not "annoy" | irritate, annoy (for people) |
| anticipate | not a synonym for simple expectation | expect |
| as good or better than | the comparison breaks | as good as or better than; or recast |
| as to whether | padding | whether |
| case | usually unnecessary ("in many cases") | recast: "many rooms…" |
| character, nature | usually filler ("of a hostile character") | hostile acts |
| claim (verb) | means "lay claim to," not "say" | declare, maintain, charge |
| compare to / with | "to" likens things; "with" examines differences | choose by meaning |
| comprise | the whole comprises the parts | "consists of"; never "is comprised of" |
| contact (verb) | vague and self-important | call, write, meet |
| currently | redundant with a present-tense verb | usually delete |
| data | plural | "the data are" |
| different than | logic favors "differs from" | different from |
| disinterested | means impartial, not bored | uninterested (for bored) |
| due to | loose for "because of" | because of, owing to |
| effect / affect | effect (noun) = result; effect (verb) = bring about | check the sense |
| enormity | means monstrous wickedness | enormousness, size |
| fact | only for what can be verified, not judgments | claim, opinion, belief |
| facility | a vague stand-in for a real place | prison, school, hospital |
| factor, feature | hackneyed; add nothing | say what happened or what it did |
| farther / further | farther = distance; further = time, degree, quantity | choose by meaning |
| finalize, -ize coinages | pompous verbs made by tacking -ize on a noun | finish, complete; use an existing verb |
| fortuitous | means by chance, not fortunate | lucky |
| he is a man who | padding | "He…" |
| hopefully | as "I hope" it's ambiguous and grates on many ears | I hope; it is hoped |
| however (first word) | at the start it means "in whatever way" | move it inside: "At last, however, …" |
| imply / infer | the speaker implies; the listener infers | choose by who is doing it |
| importantly | usually a weak connective | "What's more," or recast |
| in regard to | never "in regards to" | as regards, about |
| in terms of | padding | recast: "The salary made the job unattractive" |
| insightful | an inflated "perceptive" | perceptive |
| interesting (as an intro) | announcing interest doesn't create it | just tell it |
| kind of / sort of | loose for "rather" | rather, somewhat, or cut |
| lay / lie | lay takes an object; lie doesn't | lie down; lay it down |
| less / fewer | less = quantity; fewer = number | fewer workers, less water |
| like / as | like goes before nouns; as before clauses | "as they did then" |
| literally | not for exaggeration | cut it, or use "almost" |
| meaningful | a bankrupt adjective | say what it meant |
| nauseous / nauseated | nauseous = sickening; nauseated = sickened | "I felt nauseated" |
| personally | usually unnecessary | delete |
| possess | puffed-up "have" or "own" | have, own |
| presently | ambiguous: "soon" or "now" | use it for "soon" only |
| state (verb) | not a stand-in for "say" | say; keep "state" for "express fully" |
| that / which | that restricts (tells which one); which adds a fact, with commas | "The key that opens…" / "The key, which is bent, …" |
| try and | takes the infinitive | try to |
| unique | no degrees: without equal | unique (never "very unique") |
| utilize | prefer the plain word | use |
| very | weakens more than it strengthens | a stronger word, or nothing |
| while | loose for "and," "but," "although" | a precise connective, or a semicolon |
| would (habitual) | unnecessary when "every day" already signals habit | simple past: "Each spring he visited…" |
