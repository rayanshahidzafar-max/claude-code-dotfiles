# The Installment Plan

A one-page plan for one book in a series. It goes into the story folder as the SERIES block of `00-brief.md`, so every `story-forge` station drafts against it.

```
SERIES / BOOK #:               and its place in reading order, if that differs
INSTALLMENT TYPE:              sequel · middle book · prequel · side story · finale
SERIES QUESTION:               from the series outline
THIS BOOK ANSWERS:             the question the book before it raised
THIS BOOK ASKS:                the question that pulls readers into the next
BOOK ARC:                      inciting incident → midpoint → climax (this book's own)
WHAT READERS LOVED → TWIST:
STAKES:                        higher than last time, or different (what's newly at risk?)
PATTERN BROKEN:                which of the series' own habits this book turns over
ARCS MOVED:                    each lead and key relationship, from (start) to (end)
ARRIVALS / DEPARTURES:
PAYOFFS DUE:                   rows from the loop ledger
NEW PLANTS:                    for later books (new ledger rows)
LOOPS CLOSED / OPENED:
OPENING:                       first scene; time since the last book; recap method
ENDING:                        soft cliffhanger / read-through hook / hard (and why) / series end
CANON CHECKS:                  bible facts this book must not contradict
```

## Filling it in

- Before plotting, write down this book's inciting incident, midpoint and climax, and do the same for the books after it in dot points if you can. Sketching later books shows which threads must start now to pay off later. [Scheuerer ch7]
- Ask every book three progression questions. Does it raise the stakes on the last one? Does it hold a complete arc of its own? What is its question, and how does it answer it? [Scheuerer ch7]
- Escalate past the usual formula. When the lead is already cornered and under fire, make the corner itself start to collapse. [Scheuerer ch7]
- If you're stuck, borrow a structure template (a beat sheet, a chapter-by-chapter plot outline) and use the same one across the series. It is a skeleton to shape, never a cage. [Scheuerer ch7]
- Talk the plan through with a trusted partner who reads the genre. They ask the questions you won't. [Scheuerer ch7]
- As you finish each draft, keep a running list of what later books must reference and which arcs remain open. [Scheuerer ch11]
- Start the next book while readers are still reading this one; momentum matters in writing and in publishing. [Scheuerer ch9]
- Question every firm rule before you commit to it. An arbitrary rule about the world can make later books unrealistic or back you into a corner. [Scheuerer ch26]
- Rewrite backward from the climax, and cut any scene the climax doesn't justify. [McKee ch13]
- Every scene must bear on the book's question. Ask "and so?" of each one, and where there's no answer, cut it. [Cron ch8]
